# TGSV Launcher

TGSV Launcher is a custom launcher for the TGSV community server.

It is designed to simplify the installation and management of the
Society: Sunlit Valley modpack and its required configuration files.

## Features

- Microsoft account authentication
- Automatic installation and management of required game files
- Automatic mod and configuration management
- Launching the configured Java Edition modpack
- Simplified access to the TGSV community server
- Korean user interface

## Microsoft Authentication

TGSV Launcher uses Microsoft's standard OAuth authentication flow.

Users sign in through Microsoft's authentication service. The launcher
does not bypass Microsoft authentication, game ownership checks, licensing
requirements, or Minecraft service security mechanisms.

Access to Minecraft Java Edition game services is used only as required
to authenticate eligible users and launch the configured game environment.

## Project

TGSV Launcher is a customized project based on the open-source
Helios Launcher by Daniel D. Scalzi.

Original project:
https://github.com/dscalzi/HeliosLauncher

TGSV-specific changes include branding, Korean localization, launcher
configuration, and integration with the TGSV Society: Sunlit Valley
community server environment.
